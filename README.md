# Data Science Master Projects

This repository collects selected hands-on projects developed during my
**[professional Master's program in Data Science at ProfessionAI](https://profession.ai/corsi/master-data-science)**.

The program complements my research background with practical training in
**Python, Statistics, Machine Learning, Deep Learning, Natural Language Processing,
SQL, Big Data, and Data Visualization**.

I use these projects to strengthen my computational skills across different domains,
from exploratory data analysis and predictive modeling to text classification,
time-series forecasting, and large-scale data processing.
